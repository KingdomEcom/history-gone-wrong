Privacy Policy

Last updated: October 25, 2026

The History Gone Wrong uploader is a private tool used only by the owner of the History Gone Wrong YouTube channel. It is not offered to the public.

What data it uses

With the owner's permission (Google OAuth), the tool uses the YouTube Data API to upload the channel's own videos, set their titles, descriptions and thumbnails, and read the channel's own public video statistics (views, likes, comments).

Storage

The sign-in token is stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising.

Google and YouTube

The tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at Google security settings.

Contact

Questions: contact the channel through its YouTube About page.
